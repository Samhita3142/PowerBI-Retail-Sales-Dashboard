# Power BI Retail Sales Dashboard

## Project Overview
This project analyzes retail sales data using Microsoft Power BI to understand sales performance, profitability, and regional trends. The dashboard presents key business insights through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

## Key Features
- Monthly sales and profit trend analysis
- Sales and profit margin comparison across categories and subcategories
- Regional sales and profitability analysis
- Interactive slicers for filtering and exploring data
- Key performance indicators to support business decision-making

## Key Metrics
- Total Sales
- Total Profit
- Profit Margin
- Monthly Sales and Profit
- Regional Sales Performance

## Key Insights
- Compared sales performance across different regions.
- Analyzed profit margins to identify less profitable categories and subcategories.
- Examined monthly sales and profit trends to identify changes in business performance.
- Used interactive filters to explore sales data from different perspectives.

## Project File
The Power BI dashboard file (`Retail_dashboard.pbix`) is available in this repository. Download it and open it using Microsoft Power BI Desktop to explore the report.
